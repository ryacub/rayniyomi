# Browse redesign flows

Annotated flows for epic #1512 (R1229 to R1233). Each PDF page is one flow. Frames come from the interactive prototype, board A2. Blue arrows show the interaction to the next frame. Purple numbers point to notes under each frame. Codes such as S7 are rows in the epic's parity checklist.

This branch holds design files only. It shares no history with `main`.
